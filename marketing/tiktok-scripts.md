## Video 1: "Here's what we built" (Screen Recording)

**Format:** Screen recording of Loona + casual voiceover
**Duration:** 30s
**Hook:** Start on the dashboard, no intro fluff

```
[Screen: Loona dashboard]
"So we built this — it's a loan tracker for Filipino lenders."

[Navigate to loan detail]
"You set up a loan, it makes the schedule for you."

[Record a payment]
"Someone pays, you record it — balance updates automatically."

[Show overdue flag]
"Missed a due date? Flagged."

[End on dashboard]
"That's it. It's free. It's on the browser. We just need people to try it."

loona.ph
```

**Caption:** We built a loan tracker. It's free. We need lenders to try it. loona.ph

## Video 2: "Why we made this" (Talking Head, 20s)

**Format:** Direct to camera, no cuts, raw
**Hook:** Open with the problem, not the product

```
"There's no good loan tracker for small Filipino lenders.
The ones that exist are either for banks or cost money nobody wants to pay.

So we made one. Free. Browser lang.

It's called Loona. We're still building it
and we need lenders to try it and tell us what's off.

loona.ph"
```

**Caption:** Walang magandang tool for small lenders dito. So gumawa kami. loona.ph
