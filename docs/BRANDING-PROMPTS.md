# Loona Branding Prompts

Use these prompts with Ideogram, DALL-E 3, or Midjourney.

---

## 1. Primary Logo (Icon + Wordmark)

```
Minimal modern logo for "Loona", a loan management fintech app for the Philippines.
Combination mark with simple geometric icon and clean sans-serif wordmark.
Icon concept: abstract moon crescent combined with upward growth arrow or currency symbol.
Colors: Deep blue (#1e40af) as primary.
Style: Flat design, no gradients, professional, trustworthy.
Must work at 32px favicon size. White background.
```

**Variation A - Moon Focus:**
```
Logo for "Loona" fintech app. Stylized crescent moon forming the letter L.
Minimal, geometric, single color (navy blue). Clean modern typography.
Professional banking/finance aesthetic. Flat vector style, no shadows.
```

**Variation B - Growth Focus:**
```
Logo for "Loona" loan management platform. Abstract mark combining letter L
with upward trending line/arrow suggesting financial growth.
Minimal geometric design, deep blue color, modern sans-serif wordmark.
Clean, trustworthy, professional. Flat design, works at small sizes.
```

**Variation C - Circle/Coin:**
```
Logo for "Loona" - a lending platform. Circular logo mark with stylized "L"
inside, resembling a coin or seal of trust.
Navy blue, minimal, geometric. Paired with clean wordmark.
Finance/banking aesthetic, flat vector style.
```

## File Checklist

After generating, you'll need:

- [ ] `logo.svg` - Primary logo (icon + wordmark)
- [ ] `logo-icon.svg` - Icon only (for small spaces)
- [ ] `logo-white.svg` - White version for dark backgrounds
- [ ] `favicon.ico` - Multi-size favicon (16, 32, 48)
- [ ] `apple-touch-icon.png` - 180x180 for iOS
- [ ] `og-image.png` - 1200x630 for social sharing
- [ ] `android-chrome-192.png` - Android icon
- [ ] `android-chrome-512.png` - Android splash
